- [**Portofavolio**](https://github.com/favizz/Portofavolio): real coverage for 8,091 stops from a Go spatial-hash walkshed engine, avoiding a roughly 130 million calculation naive nearest-stop search. Transit analytics on TransJakarta's real GTFS feed, 240 routes. A batched ingestion pipeline loads about 252,000 real GTFS rows into Postgres in under 600 round trips. Live rider demo replays real buses along their real routes and estimates ride times, labeled as an estimate, not measured ridership. [Demo](https://portofavolio-rmww.vercel.app)
- [**Fraud-Detection-using-Machine-Learning-Algorithm**](https://github.com/favizz/Fraud-Detection-using-Machine-Learning-Algorithm): a 25x cut in false negatives (fraud recall from 0.02 to 0.52) from class weighting and SMOTE on a real, severely imbalanced dataset, about 100k transactions, 14% fraud. Decision Tree, Logistic Regression, and KNN implemented from scratch by a 4-person team, benchmarked against scikit-learn. My part: the preprocessing pipeline, EDA, the scikit-learn benchmark implementations, and the live demo web app. [Demo](https://fraud-detection-using-machine-learn.vercel.app)
- [**netflow**](https://github.com/favizz/netflow): 2,444+ smart meters streaming live MQTT telemetry into prepaid billing, originally an undergraduate thesis project. NestJS and MySQL backend. A 13-detector anomaly engine (backflow, tamper, sensor faults, MCB trips) is backed by 166 unit tests.
- [**genyra-familytree**](https://github.com/favizz/genyra-familytree): automatic family-tree layout across generations, no manual placement, including multi-marriage cases, from a custom multi-phase auto-layout engine on a shared-type monorepo. BFS-based consanguinity checks flag close-relative conflicts up to 3 generations before a relationship can be saved. [Demo](https://genyra-familytree.vercel.app)
